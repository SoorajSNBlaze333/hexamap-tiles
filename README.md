# hexamap-tiles

Monorepo for the `hexamap-tiles` React library.

- `packages/hexamap-tiles` — the library ([README](packages/hexamap-tiles/README.md))
- `apps/docs` — Next.js + Tailwind demo / playground

Requires Node ≥ 22.12 (`nvm use` picks up `.nvmrc`).

```bash
npm install
npm run dev        # builds the lib in watch mode + docs on http://localhost:3100
npm test           # library unit tests
```
